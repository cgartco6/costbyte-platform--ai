# CostByte Platform – AI Venture Studio

Launch your startup in minutes. AI generates business plan, logo, website, legal documents, and marketing plan. Pay in ZAR (Stripe, PayPal, PayFast, direct EFT). Fully compliant with South African law.

## Quick start
1. Clone repo
2. `npm install`
3. Copy `.env.example` to `.env` and add your API keys
4. `npm start`
5. Open `http://localhost:3000`

## Features
- Real AI content (OpenAI GPT‑4 + DALL‑E)
- Custom branding: choose colours, fonts, logo style
- Multiple payments: Stripe, PayPal, PayFast, EFT (FNB)
- Revenue dashboard with MRR & targets
- Marketing engine with SA/province targeting
- POPIA, CPA legal docs generator
- Social media compliance checker

## Deploy to production
Set `NODE_ENV=production` and use a process manager like PM2.
